## Команды curl 

**1. Проверка живости (запрос №1):**
```bash
curl -i http://127.0.0.1:4010/health```
Ответ: HTTP/1.1 200 OK, тело: {"status":"ok"}
```
**2. Повтор (запрос №4, с Idempotency-Key):**
```bash
curl -i -X POST http://127.0.0.1:4010/api/v1/orders/timor/issue -H "Idempotency-Key: test-key-1" -H "Content-Type: application/json"
Ответ: HTTP/1.1 200 OK, тело: {"order_id":"order-123","status":"issued"}```
```
**Ответы на вопросы**

Какой запрос проверяет правило повтора? с Idempotency-Key. Мок не может проверить логику не выдавать второй раз, он просто всегда возвращает пример из YAML. 

Почему нельзя класть настоящий пароль? Коллекция сохраняется в JSON и попадает в репозиторий. Любой, кто получит доступ, увидит пароль. Используются только фиктивные ключи (test-key-1).

Где фильтр страницы, а где номер вещи? Фильтр страницы - в query-параметре ?limit=20 в адресе списка. Номер вещи - в path-параметре {order_id}.
